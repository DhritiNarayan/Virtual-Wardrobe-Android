# 👗 Virtual Wardrobe

A personal wardrobe management Android application built with Kotlin that allows users to digitally organize their clothes, explore clothing categories, and create and save outfit combinations.

## ✨ Features

- **Add Clothes:** Import clothing images directly from your gallery.
- **Category Management:** Organize clothing into Tops, Bottoms, Dresses, Shoes, Accessories, and Jackets.
- **Category Filtering:** Browse clothing items by category.
- **Wardrobe Visibility:** Show or hide the entire clothing collection.
- **Outfit Studio:** Select different clothing items and create outfit combinations.
- **Save Outfits:** Save customized outfits with a name.
- **Saved Outfit Collection:** View your previously saved outfits.
- **Outfit Details:** Open individual saved outfits to view their combinations.
- **Delete Items:** Remove clothing items and saved outfits.

## 🛠 Tech Stack

- **Language:** Kotlin
- **Platform:** Android
- **UI:** XML Layouts
- **Storage:** SharedPreferences
- **Image Storage:** Local device storage
- **IDE:** Android Studio

## 📱 Application Overview

Virtual Wardrobe helps users manage their clothing digitally and experiment with outfit combinations without needing to browse their physical wardrobe every time.

The application provides a simple interface for adding clothing, organizing items into categories, and combining different pieces to create outfits.

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Android device or emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/DhritiNarayan/Virtual-Wardrobe-Android.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Run the application on an emulator or connected Android device.
